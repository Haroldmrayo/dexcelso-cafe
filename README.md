# D'Excelso Café

Sitio web estático de D'Excelso Café (Finca Villa Hanny, La Irlanda, San Vicente, Jamundí, Valle del Cauca).

- `index.html`: página principal
- `blog.html`: artículos (origen y variedades, recetas, cultura cafetera)
- `styles.css`: colores, letras y componentes
- `sitio.js`: número de WhatsApp y precio de la libra (se cambian en las dos primeras líneas)
- `img/`, `video/`: fotos y video de la finca

Se publica en Vercel con cada `git push` a `main`.
